# Frontend (React + TypeScript + Vite + Tailwind)

Scripts:
- bun run dev
- bun run build
- bun run preview

Environment:
- Copy `.env.example` to `.env` and set values:
	- `VITE_API_URL` (e.g., http://localhost:3000)
	- `VITE_GOOGLE_CLIENT_ID` (optional) to enable Google sign-in

Assets:
- `assets/side.png` is used on large-screen auth page.

Notes:
- Theme color is #367AFF (configured as `primary` in Tailwind).
